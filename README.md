# Netflix Content Portfolio Analysis

## Project Overview

This project explores Netflix's content library to understand its composition by content type, release year, and audience rating.

The analysis was carried out using Microsoft Excel, with PivotTables and charts used to summarize the data and identify key patterns in Netflix's content portfolio.

## Project Objectives

- Analyze the distribution of Movies and TV Shows.
- Identify release years with the highest number of titles.
- Examine the most common content ratings.
- Present key findings through charts and a written summary.

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel filters and data cleaning

## Dataset

The dataset contains information about Netflix titles, including:

- Show ID
- Content type
- Title
- Director
- Country
- Date added to Netflix
- Release year
- Rating
- Duration
- Listed genres and categories

The dataset was inspected and cleaned before analysis. An incomplete record and duplicate records identified during the cleaning process were removed.

## Analysis and Key Findings

### 1. Content Distribution

The analysis covered **8,786 titles**.

| Content Type | Number of Titles | Share |
|---|---:|---:|
| Movies | 6,123 | 70% |
| TV Shows | 2,663 | 30% |
| **Total** | **8,786** | **100%** |

**Finding:** Movies make up approximately 70% of the Netflix titles analyzed, while TV Shows account for the remaining 30%. This shows that Movies represent the larger share of the content library.

### 2. Release Year Analysis

The five leading release years identified in the analysis were:

| Release Year | Number of Titles |
|---|---:|
| 2018 | 1,144 |
| 2017 | 1,030 |
| 2019 | 1,029 |
| 2020 | 953 |
| 2016 | 901 |

**Finding:** Among these five years, 2018 had the highest number of titles, followed by 2017 and 2019. The figures show that these years are strongly represented in the dataset.

These results describe the release years of the titles in the dataset. They do not, on their own, measure Netflix's annual growth or the number of titles added to the platform each year.

### 3. Content Ratings Analysis

The five most common ratings identified were:

| Rating | Number of Titles |
|---|---:|
| TV-MA | 3,205 |
| TV-14 | 2,155 |
| TV-PG | 860 |
| R | 798 |
| PG-13 | 490 |

**Finding:** TV-MA was the most common rating, followed by TV-14. This indicates that titles carrying mature-audience and older-teen ratings are strongly represented in the library.

TV and movie ratings use different classification systems, so their meanings should be considered when interpreting the results.

A summary worksheet brings together the main findings and conclusion.

## Recommendations

Based on the analysis:

- **Review the content mix:** Netflix's library in this dataset contains more Movies than TV Shows. Further analysis could help determine whether this mix aligns with audience demand.
- **Investigate release-year patterns:** The high representation of titles released between 2016 and 2020 could be explored further to understand changes in the library over time.
- **Examine rating distribution:** The large counts for TV-MA and TV-14 provide a useful starting point for investigating how content is distributed across audience rating categories.
- **Use additional performance data:** Viewing figures, subscriber preferences, and engagement metrics would be needed to determine which content types and ratings perform best with audiences.

## Conclusion

This project provided an overview of Netflix's content library using Excel. Movies accounted for approximately 70% of the titles analyzed, 2018 had the highest title count among the five leading release years reviewed, and TV-MA was the most common rating.

The findings describe the composition of the available dataset and provide a starting point for further analysis of content categories, geographical distribution, audience segments, and historical trends.
